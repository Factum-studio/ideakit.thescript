# IDEAKIT

[![PHP Version](https://img.shields.io/badge/PHP-8.4.23-777BB4?logo=php)](https://php.net)
[![Yii Framework](https://img.shields.io/badge/Yii-2.0.55-40b3d8?logo=yii)](https://www.yiiframework.com/)
[![License: Script Agency](https://img.shields.io/badge/License-Script%20Agency%20Proprietary-blue.svg)](./LICENSE.md)

**IDEAKIT** - это Telegram-бот, который последовательно показывает начинающим предпринимателям из РФ/СНГ подготовленные digital-бизнес-идеи. Пользователь может получить следующую идею, открыть готовый подробный анализ или оставить заявку digital-агентству.

Проект построен на принципах **Clean Architecture** и **Domain‑Driven Design (DDD)** с использованием **CQRS**, что обеспечивает высокую масштабируемость, поддерживаемость и готовность к выносу модулей в отдельные микросервисы.

---

## О системе

IDEAKIT разработан как закрытое программное обеспечение для внутреннего использования Script Agency и предоставления услуги клиентам агентства.

**Ключевые возможности:**

- **Последовательный показ идей** - лента активных идей для вашего бизнеса.
- **Готовые подробные отчёты** - доступен структурированный документ (проблема, аудитория, бизнес‑модель, конкуренты, риски, план MVP, первые шаги).
- **Экспорт в PDF** - отчёт можно скачать в виде PDF-файла (генерируется один раз и кэшируется).
- **Заявка в агентство** - пользователь оставляет комментарий, лид регистрируется и обрабатывается сотрудниками через веб‑портал.
- **Управление статусами заявок** - полный жизненный цикл от `SUBMITTED` до `CLOSED`/`CANCELLED`.
- **Административный веб‑интерфейс** - для просмотра и изменения статусов заявок, управления каталогом идей.
- **Услуги вашего технического партнёра** - список технических услуг Script Agency для быстрого поиска и обсуждения ваших зон роста.  

**Архитектурные принципы:**

- **Чистая архитектура** - строгое разделение на презентационный, прикладной, доменный и инфраструктурный слои.
- **CQRS** - разделение команд (запись) и запросов (чтение) для оптимизации производительности.
- **DDD** - бизнес-логика инкапсулирована в агрегатах.
- **Модульность** - Telegram-бот реализован как отдельный модуль в монолите, но спроектирован для быстрого выделения в микросервис.
- **Интеграция с AI-микросервисом** - фоновое пополнение каталога новыми идеями (Python, REST API).

*Подробное описание архитектуры и диаграмм приведены в документации ([Документация](./docs/README.md))*.

## Процесс развёртывания (Deploy)

### Требования к окружению

- PHP 8.1 или выше
- PostgreSQL 17.10
- Redis 8.2.8
- RabbitMQ 4.3.4
- Composer 2.10.2
- Nginx / Apache (или встроенный сервер для разработки)
- Доступ к Telegram Bot API (токен бота)
- часовой пояс runtime — UTC

### Локальный запуск (development)

В среде с утверждёнными версиями PHP и Composer доступны проверки Composer и Yii2 foundation:

```bash
php -v
composer --version
composer install --no-interaction --prefer-dist
composer check-platform-reqs
php requirements.php
```

Запуск web-, console- и worker-процессов будет документирован после реализации воспроизводимого окружения. Реальный `.env` в репозитории не создаётся.

### Развёртывание на продакшн (production)

Продакшн-развёртывание временно отключено. Оно может быть включено отдельной задачей только после настройки и проверки утверждённого runtime, web-конфигурации и серверных команд на целевом окружении.

Настройка webhook Telegram-бота пока не документируется как действующая процедура: соответствующая консольная команда в приложении не реализована.
